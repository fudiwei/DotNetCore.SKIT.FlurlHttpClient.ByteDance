# SKIT.FlurlHttpClient.ByteDance.DouyinOpen

基于 Flurl.Http 的抖音开放平台 API 客户端 SDK。

## 功能特性

- 封装抖音开放平台 API。
- 提供了 AES、MD5、SHA-1、SHA-256、HMAC-SHA-256 等算法工具类。
- 提供了授权链接生成、JSBridge 签名、回调通知事件解析、手机号码解密等扩展方法。
- 配合 [SKIT.FlurlHttpClient.ByteDance.MicroApp](https://www.nuget.org/packages/SKIT.FlurlHttpClient.ByteDance.MicroApp) 模块，可对接抖音小程序开放平台。
